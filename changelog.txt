WaEnhancer 1.6.6

[UPDATED]
* Merged upstream through c2b1b6fc.
* Supports WhatsApp and WhatsApp Business 2.26.38.xx through 2.26.43.xx. Versions 2.26.34.xx through 2.26.37.xx are no longer supported.
* Uses stable YukiHookAPI 1.5.0 and official DexKit 2.3.0, preserving libxposed API 101 and the fork's Miuix manager.

* Updated stable app dependencies and build tooling, including Room 2.8.5, DataStore 1.3.0, OkHttp 5.5.1, WebKit 1.18.0, Kotlin 2.4.21, AGP 9.5.1 and Gradle 9.9.0.

[NEW]
* Optional notifications for blocked calls. Per-contact privacy takes precedence over global call-blocking settings.
* Optional native status bar for IG Status, with RecyclerView-based status items.
* Option to hide delivered receipts from unknown numbers and diagnostics for Magisk DenyList blocks.

[FIXED]
* Update checks compare version numbers and commit ancestry, so a newer installed build no longer offers an older GitHub release.
* Fixed Anti-Revoke compatibility on WhatsApp 2.26.43 and older supported versions, stale deletion dates on recycled messages, and repeated database work when displaying messages.
* Improved hidden read, played and delivery receipts, including LID tracking, persistent status blue-tick state and media re-uploads.
* Fixed excessive blue-tick sends, repeated retries for missing messages, locked-chat crashes and contact filtering.
* Theme imports recover interrupted replacements. Settings XML and output directories are validated before saving.
* The CSS editor restores unsaved drafts, supports image imports, follows the app theme and recovers from renderer failures.
* Improved contact selection, storage permission checks, operation dialogs, list state, keyboard behavior and accessibility in the manager.

[IMPROVED]
* Reduced repeated work during startup, scrolling, tab changes and IG Status updates. Custom wallpapers load on the first Home frame.
* The built-in bootloader spoofer was removed upstream. Custom keybox support remains available.

[COMPATIBILITY]
* Requires Android 13 or later and an Xposed framework supporting libxposed API 101.
* Existing fork package IDs, settings recovery, deleted-message backups and signing identity are preserved.
